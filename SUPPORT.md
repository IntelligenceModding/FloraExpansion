## Bug Reports

If you have found a reproducible problem with Flora Expansion, please use the **Bug Report** issue form.

Examples include:

- crashes;
- plant, crop, or fruit growth problems;
- leaf litter or pine litter behavior problems;
- pebble placement or interaction problems;
- basket harvesting or inventory problems;
- crate storage, locking, tying, or item-transfer problems;
- wooden bucket behavior problems;
- food, juice, jam, or other consumable problems;
- flax or linen progression problems;
- cherry, apple, blueberry, or strawberry behavior problems;
- giant cactus or other desert-content problems;
- world-generation problems;
- rendering or texture problems;
- JEI integration problems;
- multiplayer behavior problems;
- compatibility problems;
- other unexpected in-game behavior.

Before submitting a bug report:

- make sure you are using a Flora Expansion version intended for your Minecraft version;
- make sure your mod loader and any required dependencies are compatible;
- check whether the issue has already been reported;
- try to reproduce the problem consistently.

Please include your Minecraft version, Flora Expansion version, mod loader version, relevant dependency versions where applicable, reproduction steps, and logs or crash reports where applicable.

If the problem involves a specific block, item, plant, crop, food, biome, world-generation feature, growth stage, interaction, storage feature, or optional integration, include that information as well.

## Feature Requests

Suggestions for new features and improvements are welcome.

Feature requests may include:

- new plants or natural blocks;
- new foods or forageable items;
- new crops or fruiting plants;
- litter or pebble improvements;
- basket or crate improvements;
- flax or linen improvements;
- new desert or cactus content;
- world-generation improvements;
- JEI integration improvements;
- compatibility improvements;
- visual improvements;
- other additions that fit the purpose of Flora Expansion.

Please use the **Feature Request** issue form and explain what you would like to see added or changed and why it would be useful.

For larger features, discussing the idea before beginning development is recommended.

## Version Support Requests

Flora Expansion may be maintained across multiple Minecraft versions and mod loaders.

If you would like support for another Minecraft version or mod loader, please use the **Version Support Request** issue form.

Before submitting a request:

- check the available repository branches;
- check the CurseForge project page;
- check the Modrinth project page;
- make sure support for the requested version or loader does not already exist.

Submitting a request does not guarantee that the requested Minecraft version or mod loader will be supported.

- questions about giant cactus content;

## Security Issues

Potential security vulnerabilities should not be reported through a normal public bug report.

If you believe you have found a security-sensitive issue, report it privately to:

**report AT intelligence-modding DOT de**

Please include enough information to reproduce and understand the issue, including affected versions, reproduction steps, relevant logs, and the potential impact where possible.
